# Rasteratops

Rasteratops is an immutable Linux distribution for handheld gaming devices,
a fork of ROCKNIX, itself a fork of JELOS. It develops the experience its
maintainer wants and makes qualified builds available to others.

The 0.0.1 identity release is in preparation. Current work and its verification
are tracked in the [release issue](https://github.com/rasteratops/distribution/issues/344).
Updates for this release are manual; use the instructions attached to the
[release](https://github.com/rasteratops/distribution/releases).

The project does not accept sponsorships and has no Discord or community
channel. Public contributions are not solicited. Existing upstream credits,
component licences and corresponding source remain part of the distribution;
see [LICENSE.md](LICENSE.md) and [TRADEMARK.md](TRADEMARK.md).

Development starts with [AGENTS.md](AGENTS.md). The retained ROCKNIX paths,
partition labels, hostnames and command names preserve installed-system
compatibility; the player-visible identity is Rasteratops.
