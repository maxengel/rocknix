# Trademarks

**pixelelated**, **Rasteratops**, **Blitterbot** and the project's logo are this project's marks.
They say that a build came from this project and from nobody else, which is the
one thing the code's licence cannot say. The code is free software under the
GNU GPL version 2 (`LICENSE.md`); this file is about the name, not the code.

## What the marks allow

- A build published by this project carries the name and the logo.
- Naming the project -- in a review, a guide, a bug report, a comparison, a
  link -- is fine and needs no permission.
- Saying that something works with pixelelated, or was made for it, is fine,
  as long as it does not read as if this project made or approved it.

## What they do not allow

- A modified build, a fork, or anything built from this tree with changes is
  not pixelelated. Rename it and remove the logo before distributing it. The
  code's licence goes with you; the name and the logo do not.
- Nothing may use the name or the logo in a way that suggests this project
  made, approved or endorses it.
- "Blitterbot" names this project's automation and its accounts. Do not
  operate anything under that name.
