## Risk assessment

**As the tree stood before this pass (`02546235c1`), ranked by what it would have cost a player:**

1. **A configuration line ran a command** (gpt G3-D-01): `conf_valid` accepted `RANDOM=`, `SECONDS=`, `LINENO=` and an escaped dollar, and bash evaluates an assignment to those as arithmetic, which runs a command substitution -- shown by a canary on the host, from a file `bash -n` passes. Fixed in three copies (the shell-owned names, backslash-dollar before `(`, `[`, `{`), with the NUL byte (claude G3-D-02) closed beside it.
2. **The settings sorter installed a truncated copy** (gpt G3-D-04): a producer failing after the hostname line passed the non-empty check and the `mv` went ahead -- the #102 shape, defaults winning over a player's settings. Fixed: the rename gated on the pipeline.
3. **A password readable in the interface's log** (gpt G3-E-01): the masker ended a value at the second single-quote splice. Fixed in `StringUtil`, two cases.
4. **A player's newer pending marker removed by an older acknowledgement** (gpt G3-D-03), **a migration reading a bare pointer as a whole line** (claude G3-D-05), **a restore gate proceeding on a mount state it had not read** (gpt G3-D-07), **a scrub leaving a cut line's quoted tail** (gpt G3-D-09): each a Medium, each fixed with a case.

   **Why G3-D-09 is a Medium beside G3-E-01's High, both credential exposures** (the second opinion asked): G3-E-01 is the masker on every line the interface logs from now on -- each `sh -c` it builds with a spliced password would have left the password readable, on every device, on every boot. G3-D-09 is `cloud_log_scrub`, the one-time pass that masks what *earlier* builds wrote to the persistent `cloud_sync.log`: its gap was a line already cut short before its `failed (...)` suffix, whose quoted value's tail survived the first mask, in a log the new scripts no longer write credentials into at all. One is an ongoing leak in the writer; the other is a corner of a historical clean-up. Same kind of exposure, an order less of it.
