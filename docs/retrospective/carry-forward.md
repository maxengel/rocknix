# Themes to carry into every retro

Started 2026-09-11. The `mini-retro` skill writes dated retros beside this file; this
one holds the standing questions each of them asks.

- **Time to play** (D-CLOUD-098, `.claude/rules/time-to-play.md`): what did this phase do
  to interface → first frame and exit → next first frame? Maintainer, 2026-09-11: "a good
  goal for us always to be cognizant of and to rally around, because it can help guide our
  decision-making."
- **Can it be done on the VM?** (`vm-first.md`, D-QA-007/015/017): did any proof run on a
  person's device, and was the written answer there first?
- **One story for the player** (D-CLOUD-095, #134): did the phase add a second home,
  word or setting for something the player experiences as one thing?
- **Least surprise** (D-UI-042, `.claude/rules/least-surprise.md`): did anything this phase
  shipped do something other than what its screen led the player to expect, or do the same
  thing differently in two places?
