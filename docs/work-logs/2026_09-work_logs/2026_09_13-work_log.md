Two things learned in the fixtures, neither a blindspot:

- **bwrap cannot make a mountpoint under a read-only bind.** `--ro-bind /usr
  /usr` then `--ro-bind <fake> /usr/config` fails with "Can't mkdir
  /usr/config: Read-only file system" because the host has no `/usr/config`.
  Bind `/usr` a subdirectory at a time (`for d in /usr/*/`) so `/usr/config`
  is created on the tmpfs root. Case k does this.
- **Do not mark a binary fixture with `echo >>` and unmark it with `sed
  '$d'`.** The PNG's last bytes carried no newline, so the delete took eight
  bytes of `IEND` with the marker; guest c's `7z.png` was restored from
  `/usr/config`. Mark a text file, or keep a copy.

## 01:05 UTC -- #142: FTP's "missing" is not rclone's "not found"

The #133 matrix's FTP cells (pyftpdlib) failed nine of the round trip's
checks on `ec12767b26`, reproduced tonight exactly (90/99). One cause: the
server answers a missing folder with `501 "No such directory."` where the
standard reply is 550; rclone maps 550 to "directory not found" (exit 3) and
relays 501 as a plain error (exit 1). Every branch that read exit 3 as "not
there yet" read the 501 as "your cloud is broken" -- the content scan printed
no rows and said the cloud couldn't be read, the wizard's folder setter
refused a folder that did not exist yet (and two later checks failed
downstream of the unchanged conf). The same first copy into a new folder
failed its destination listing, and `--retries 1` made that the whole run.
