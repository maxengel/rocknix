## 18:35 UTC — The mechanism for the rule

`tools/fork-package-freshness` (`3834edb658`): enumerates the fork-introduced
packages from `git diff --diff-filter=A upstream/next next`, resolves each
latest release by host (GitHub, GNOME cache.json, GNU/savannah listings,
webkitgtk.org, ruby tags, rclone), compares commit pins with their default
branch, honours `# freshness: pinned -- <why>`, and exits 1 on BEHIND, 2 on
UNKNOWN. Proven to fire: brotli held back to 1.1.0 → BEHIND, exit 1. Its
first honest UNKNOWN was unifdef's home site timing out; the fix was a
GitHub fallback for that one host, not a softer exit code. Registered in
`fork-workflow.md` ("When to merge up"), the tool index, and the pre-push
guard.
