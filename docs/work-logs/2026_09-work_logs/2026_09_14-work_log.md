## 02:05 UTC — Keeping the truth of device actions: a rule and a tool (D-QA-025)

The maintainer asked what to add to the instruction files so the harness keeps track of
the truth behind claims about device behaviour. Two things. The rule
(`engineering-practices.md` § A device's state is read from the device): before saying
what did or did not happen on a device, read the device's own record -- the previous
boot's journal, its ssh logins, the unit log, the boot id -- and treat the transcript's
tool result as one witness; when they disagree the device wins and the disagreement is
reported; answer "did you do X" with evidence, not memory; correct every place a wrong
statement landed, in the same session. The tool (`tools/device-act`, fork-only, in the
pre-push guard's personal list and `fork-workflow.md`): every state-changing act on a
device runs through it, and it appends BEGIN and END lines with the device's boot id
before and after to `/workspace/artifacts/rocknix-device-actions.log`, outside the repo
and outside any session scratch -- a changed boot id is a reboot whatever anyone
remembers. Self-tested on guest a with a read-only command.

## 14:10 UTC — D-RA-013 built: the offline cache follows the interface's game index (#184 notes 3b/5b)

What the client can do, read from its source: `rom_cache.cache_game(id, hash, credentials, ua, storage, config)` caches a game from an id and a hash with no file read (patch by id, unlocks by id, achievementsets by hash, a session); `add_rom_to_cache` adds only the hash lookup (`gameid`), the `gameid:<hash>` alias row and the `sourceRomPath` stamp on the patch row, and the ids export rewrites itself on every cache write. Where the index lives on disk, which the design hinged on: the hasher's `checkCheevosHash` saves the game to `recovery/<system>/` **with the hash and no id** -- the id is decided afterwards in `ThreadedHasher::run` and lived in memory until the gamelist was written at a clean exit, which a `reboot` over serial never is (guest d had recovery files from launches and no gamelist at all).
