# 2026-08-17 Work Log

## Cloud-setup wizard round 5: heights, info rows, authorize collision

- Tester round 5 on the wizard:
  - Pages now use the standard large-menu height (the 0.75-screen cap
    from MenuComponent::updateSize; buttons anchor bottom via the
    grid), so the window no longer jumps between steps.
  - Informational rows are non-selectable (ComponentListRow.selectable
    = false, same machinery as group headers); on the connect page only
    CURRENT PASSWORD is selectable and opens the shared view/change
    page.
  - The CHECKING overlay no longer covers page content: --info and
    --connected are fast local calls and now run synchronously; only
    the network-bound --check keeps GuiLoading.
  - Create-remote instructions renumbered from "1. RUN: rclone config".
- Real blocker root-caused: `rclone authorize "dropbox"` on the
  computer fails with "listen tcp 127.0.0.1:53682: bind: address
  already in use" because the step 2 tunnel (`ssh -L 53682:...`)
  already binds that port on the computer - an inherent collision.
  The supported path is auto config = Y (the tunnel exists so the
  sign-in URL opens in the computer's browser); rclone's own prompt
  steers headless users toward N, so the page now carries an
  IMPORTANT note forbidding authorize. Device-side, the same bind
  error strikes if an interrupted `rclone config` leaves its auth
  webserver on 53682: --info now reports AUTH_PORT=free|busy and
  --free-auth-port clears stale rclone config/authorize processes,
  surfaced as a warning action row on the configure page.
