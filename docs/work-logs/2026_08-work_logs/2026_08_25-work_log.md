# Work log — 2026-08-25

## Consolidated the agent rules and repaired the upstream guard

Retired the Copilot-era files now that Copilot is out of the toolchain (Claude,
Crush, and our own harness remain). `.github/copilot-instructions.md`,
`.github/shared-copilot-knowledge/`, the checked-in `tmp/shared-copilot-knowledge/`
and the stray root `compare-prompt-versions.sh` are gone — 66 files. What was
genuinely unique in `copilot-instructions.md` (patch generation, the `package.mk`
field checklist, the templates) became `.claude/rules/packaging-and-patches.md`,
scoped to `packages/**` and `projects/**` so it loads when it is relevant.

Repaired drift the earlier move left: the rules referenced each other by their old
`*.instructions.md` names, and several still described `applyTo` frontmatter that
is now `paths:`. `learning-capture.md` still defined a "memory" as a Copilot
`store_memory` call — a tool that does not exist here — so it now describes the
file-based store and says plainly that a memory alone is never enough, since it
lives outside the repo and nobody else reads it.

**The find worth keeping:** `.githooks/pre-push` was installed as the relative
`core.hooksPath=.githooks`. That resolves against the working tree being pushed,
and a correctly built `pr/*` branch has no `.githooks/` in it — removing it is the
point of `git rebase --onto upstream/next`. So the guard was absent from exactly
the branches it guards; both PR worktrees were unguarded and had always been.
Fixed by installing it by absolute path, which every branch can see.

Six personal paths were also missing from `PERSONAL_PATTERNS` and would have
travelled upstream: `CLAUDE.md`, `.github/sessions/`, and four fork-only tools
(`cloud-test-backend`, `cloud-round-trip`, `lint-audit-artifacts`, `vm-visual-qa`).
`tools/` is mostly upstream's, so ours have to be enumerated. Added an
unlisted-artifact check that warns on any `next`-only file outside `packages/` and
`projects/` the list does not recognise — a warning, not a block, because features
merge into `next` before being PR'd, so next-only does not prove personal.

Verified by construction rather than by absence: a synthetic PR branch carrying
`tools/cloud-test-backend` is blocked; with the pattern removed the warning fires
instead; a real clean PR branch passes silently. Registered as blindspot 14 — a
guard with no observed positive is a guard with no evidence.
