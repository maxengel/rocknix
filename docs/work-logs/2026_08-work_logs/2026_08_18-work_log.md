## Issue #30 executed: restore was broken on shipped builds

- Headless VM QA harness established (reusable): the profile's
  virtio-gpu-gl device refuses `-display none`, so take
  `generic-x64-vm qemu-args`, swap in `virtio-gpu-pci`, point
  `-serial`/`-monitor` at unix sockets under /tmp/claude-1000 (the
  scratchpad path exceeds the 108-byte sun_path limit), and drive the
  guest by piping shell into `socat - UNIX-CONNECT:...`. SSH is off by
  default on a fresh image, so serial is the only way in.
- **P1 defect found:** restore aborted partway on the 20260817 build -
  `unzip: 'storage/.config/ppsspp/assets/Roboto-Condensed.ttf' exists
  but is not a regular file`, rc=1, no reboot, config half-restored.
  `zip -r` follows symlinks (ppsspp assets, hypseus fonts/pics/sound
  point into /usr), storing targets as regular files; busybox unzip
  then refuses to overwrite the live symlink and aborts everything.
  Fixed by archiving `find -type f` only (358eb53d3f), merged through
  the QA chain (566e6dc701). Coverage proved: of 164 fewer entries, 32
  are bare directory entries and 132 are OS content behind symlinks;
  every real config file retained; archive 47MB -> 37MB.
  Note the near-miss: extracting to an empty scratch dir returned 0 -
  only extraction onto the populated live tree reproduced it.
- Other ACs verified with planted real credentials: zero secrets and
  zero bluetooth keys in the zip, corrupt-zip restore fails without
  rebooting or marking, symlinks intact post-restore, archive rotation
  capped at 3 outside the cloud allowlist.
- **Assumed-undone #2:** #31 is not greenfield - ES main.cpp
  (test/qa-integration) already ships a FINISH RESTORE SETUP page
  consuming `.restore-finish-pending` with four masked credential rows
  and a wifi reconnect. It consumes the marker on *show* (the exact
  crash-unsafe pattern the futro predicted), has no verification, and
  omits device password / cloud remote / controllers. #31 rescoped to
  upgrade it. Register entry 1 updated: grep the *other* repo for the
  feature's identifiers before calling anything greenfield.
- Register gains entries 6 (verifying a consumed artifact too late -
  use a control artifact) and 7 (archiving trees containing symlinks).
