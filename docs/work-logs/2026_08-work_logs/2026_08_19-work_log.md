### The finding that made this non-optional

Upstream reworked the ES package: **archive instead of git clone**, and
`CMakeLists.txt` now declares GLES/GLES2/GLES3/GL **mutually exclusive
with a `FATAL_ERROR`**. Our `package.mk` still passes `-DGL=1` *and*
`-DGLES2=1` when both are available, which the new ES refuses to
configure. Building the new ES against the old recipe fails outright.

Reconciled recipe: upstream's file, with only the source fields changed
back to the fork's git clone (`PKG_SITE`, `PKG_URL`,
`PKG_GIT_CLONE_BRANCH`, `GET_HANDLER_SUPPORT="git"`), keeping
`-DGLES3=1`, the `${OPENGLES}` dependency and the new `makeinstall`.
Dropping `PKG_PATCH_DIRS+="${DEVICE}"` is safe - the package has no
`patches/` directory.
