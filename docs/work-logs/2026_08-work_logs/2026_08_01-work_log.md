# 2026-08-01 Work Log

## UTM boot failure: whitespace in AdditionalArguments

- Tester hit "qemu-x86_64-softmmu: -p: invalid option" booting the v5
  bundle: UTM splits its QEMU AdditionalArguments on whitespace, so the
  injected full SSH command (ssh -L ... -p 10022 ...) shattered into
  stray options. Generalizable rule: any value injected through UTM's
  argument list must be a single space-free token.
- Fix (419de5513d): fw_cfg key renamed to opt/org.rocknix.cloud_ssh_port
  carrying only the port number; the 095-cloud-ssh quirk validates it
  (digits, 1-65535) and assembles the full command guest-side, keeping
  tunnel + target in one place. Both launcher paths verified to emit no
  argument containing whitespace; quirk logic simulated standalone.
- Rebuilt (quirks+image stamps cleared), published
  dev-generic_x64-20260802, verified the shipped bundle's args and the
  in-image quirk, updated #26.
