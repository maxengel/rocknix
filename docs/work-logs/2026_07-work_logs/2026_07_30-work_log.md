# 2026-07-30 Work Log

## Cloud setup rebuilt around rclone's interactive config (web GUI retired)

- Tester verdict on the web GUI: worse than the CLI — never asked to
  authenticate the backend or choose directories. Grounded why: the GUI's
  config API is non-interactive by design (returns questions, cannot run
  OAuth); rclone-webui-react is effectively unmaintained. A live probe of
  the rc state machine confirmed OAuth stops at "*oauth-islocal" needing a
  browser on localhost:53682.
- Decision (user): wrap rclone's interactive config rather than rebuild a
  web UI. cloud_setup now shows big-text SSH instructions (command +
  root password from get_setting root.password), including the
  -L 53682:localhost:53682 tunnel so the provider sign-in opens in the
  connecting computer's browser; optional ssh:// QR for phone SSH apps;
  on return it VERIFIES the remote (rclone lsd with timeouts) and points
  at `rclone config reconnect` when the sign-in didn't stick.
- The whole VM address-discovery apparatus collapsed: the loopback SSH
  command is a fixed string on every host platform, so both launchers
  inject it via fw_cfg (opt/org.rocknix.cloud_ssh), the quirk became
  095-cloud-ssh (also cleans the retired cloud_setup_url), and the macOS
  helper script + Gatekeeper dance + web-GUI port forward are gone.
  Profile v5. Solves Linux/macOS/Windows-via-WSL2 uniformly.
