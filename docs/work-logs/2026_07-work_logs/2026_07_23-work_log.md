# Work log — 2026-07-23

## 04:40 UTC — cloud-sync: decided issue #5 finding #1 (restore-side `--delete-excluded`)

- **Decision:** option 1 — `cloud_restore` `load_config` now strips `--delete-excluded`
  unconditionally (same pattern as the `--verbose` strip). A `sync` restore keeps mirror
  semantics within the saves allowlist but can never delete the non-save library.
- **Intent framing (maintainer):** restore serves (1) fresh-device restore of
  saves/savestates/screenshots and (2) multi-device movement via the cloud. The real
  long-term answer for use case 2 is conflict resolution, not delete flags. ROM/BIOS
  sync, if ever, belongs to system backup/restore — not the gamesave flow.
- Implemented on `feature/rclone-cleanup` (uncommitted at time of writing); instruction
  file `rclone-cloud-sync.instructions.md` updated to record the decision.
- Follow-ups from the #5 punch list: RSYNCRMDIR (#3), `--progress-terminal-width`
  parity (#6 remainder), rocknix.org docs items.
