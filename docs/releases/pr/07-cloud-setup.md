Title: rclone: cloud storage set up on the device, with a sign-in window

Cloud storage can now be set up from the couch. CONNECT OR REPAIR CLOUD STORAGE lists the providers rclone supports with a recommended shortlist first; a form asks each provider's questions in plain words; Dropbox, Google Drive and OneDrive sign in on the provider's own page in a single-purpose web view that refuses to leave the provider's host, typed on the on-screen keyboard or from the player's phone through a QR code, where the phone is only a keyboard and never where the sign-in happens; and the connection is kept only once the provider answers. A remote left behind by an abandoned sign-in is removed. Each device gets a stable name in the cloud, so two devices never overwrite one another's backups.

It carries the setup, remote, sign-in, device-id and network-ready scripts; the sign-in window (a WebKitGTK view, one host, no address bar) and the web stack it needs, which is new to the tree: webkitgtk 2.54 with two build patches, libsoup, libpsl, glib-networking, gnutls pointed at the shipped CA bundle, libtasn1, woff2, harfbuzz-icu, openjpeg, brotli, ruby, unifdef, and GStreamer with its base and bad plugin sets; qrencode for the code on screen; and the rclone recipe, which moves rclone to 1.75.1 and installs every cloud script, this change's and the saves change's, since it is one file.

I tested the sign-in flow on the virtual machine with a test account and the page-lifetime checks under AddressSanitizer, measured the sign-in window's memory there, covered the provider forms' text rules with the interface's unit tests, and connected my own Dropbox from an RG35XX SP and, tonight, from a Retroid Pocket Nova, where I found and fixed a script error on the phone page and a gamepad the window could not open. The network-ready check waits while a link comes up, which I proved with the link cut and restored on the VM. Which files move and when is the saves change's; Syncthing is untouched. No kernel, bootloader or device tree changes. It depends on the network change before it, whose scripts it reads the same truth from.
